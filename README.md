# [CatSwitch](https://switch.cat/)

Automatically switch your Twitch category and stream title based on the game you're playing.

![CatSwitch](https://switch.cat/wp-content/uploads/2026/07/catswitch_007.png)

## How it works

CatSwitch detects and categorizes all your games in real time.
Your Twitch category updates the moment you switch games or apps, so you never have to change it manually again.

Exclude specific apps, adjust stream titles, and set up category presets to match exactly how you stream. Everything runs quietly in the background, keeping your channel accurate without breaking your flow.

## Features

- Automatic game detection & category switching
- Assign stream title presets to specific games
- Multi-account support
- Themes
- Compact view
- App updater

## Build

```bash
pip install -r requirements-dev.txt
python package.py --installer
```
